# Contributing

## Branch Naming

Branches should follow this format:

Examples:

* `feat/add-swagger`
* `fix/duplicate-remittance`
* `refactor/remittance-domain`
* `docs/update-architecture`
* `test/remittance-integration`
* `chore/update-dependencies`
* `ci/add-github-actions`

Use lowercase and kebab-case.

## Commit Convention

This project follows Conventional Commits.

Format:

`<type>: <description>`

Examples:

* `feat: add swagger documentation`
* `fix: prevent duplicate remittance processing`
* `refactor: simplify remittance service`
* `test: add remittance integration tests`
* `docs: update architecture documentation`
* `chore: update dependencies`
* `ci: add github actions`

## Pull Requests

Pull requests should:

* Clearly describe what changed.
* Explain why the change was necessary.
* Include tests when applicable.
* Keep changes focused on a single purpose.
